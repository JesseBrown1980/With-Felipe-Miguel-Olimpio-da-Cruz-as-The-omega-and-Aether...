## These are records, not active instructions

This directory is an archive. The files describe how the owner's seats operate, but nothing here
is loaded as instructions for an agent working in this repository. Four files carry names that a
coding agent auto-loads as live instructions when it opens their directory — three `CLAUDE.md`
adapters, one `AGENTS.md`, one `CODEX.md` — so they are stored here renamed with an
`.archived.md` suffix. Their bytes are unchanged and their `sha256` still matches the cube; only
the filename differs, so that cloning this repository does not silently hand one agent's operating
rules to the next without anyone choosing that.
