### Rules (read before touching anything)

- **Read-only on every original.** Finding, hashing, and copying a body into a zip is read-only and
  needs no further go. **Running a codec/engine to regenerate is different** (see next rule).
- **E != 0 only on the owner's go.** Never run a regeneration engine or codec on an **original**,
  and **never on the SOVLINUX drive**. Regeneration runs only on **copies in a scratch folder on
  ACER's free 500 GB**, and only after the owner says go. Pick the drive with the free space; this
  file calls that folder `<SCRATCH>` (for example `D:\asolaria-regen-2026-10-18\` or
  `C:\asolaria-regen-2026-10-18\` — create it; do not use SOVLINUX).
- **Zip everything you send.** The relay drops `.rs` (and other code) attachments, so nothing
  travels loose — one `.zip` per numbered item below.
- **Report each file's size (integer bytes) and sha256** for everything you send; integer-only
  reporting (byte counts and hex, no float stats).
- **Privacy (OWNER-RULES 5).** Never send third-party private data: no chat/phone/WhatsApp exports,
  banking or family/personal files, other people's data, or **any** credential (`*.pem`, `*.key`,
  `id_rsa*`, `*.env`, `*token*`, `*.ed25519*`, wallets, browser profiles). If an item shares a folder
  with such files, send only the item's own files. If unsure, do not send it — list it with the path
  and reason. The five operator names already in the owner's code are authorized as written
  (OWNER-RULES 5); add no surnames the files do not already carry.
- **Held items stay held.** `gnn-reverse-gain.mjs` MASK_GLYPHS set, `vote_quorum.rs` daemon source,
  and the 47D reverse-gain variant are owner-held (OWNER-RULES 7j): do **not** retrieve, port, or
  quote them. Reproduce their absence; do not substitute values.
- **Scoped absence (OWNER-RULES 4a).** Where a body is not here, the status says exactly the scope
  searched ("not on ACER", "existed somewhere, not on ACER", "only in cloud session 9ebd6119",
  "not built in this build"). Never "does not exist / never existed / nowhere". Where no pin was
  recorded, this file says **"not recorded"** and gives the search to run.

### How to send

One zip per numbered item, named **`<slug>-2026-10-18.zip`** (the slug is in each item's heading).
For a multi-file item, put all of that item's files in the one zip. PowerShell:

```powershell

# then zip into scratch
```

report `name | bytes | sha256 | expected | match(1/0/na)`.
