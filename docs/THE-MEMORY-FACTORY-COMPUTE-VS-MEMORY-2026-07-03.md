## The substrate is not the GPU
The point is not "GPUs are useless." It is sharper: **the substrate does not have to be GPU-bound.** A GPU is useful for dense tensor passes, vision, training bursts, local model acceleration. But the Asolaria civilization layer does not need to live inside the GPU — it can live in **storage, catalogs, glyphs, cubes, recall, Hilbra, and agents that process slices as they arrive.**

- **CPU** = the always-running engine / scheduler / verifier.
- **GPU** = an optional accelerator.
- **Hard drive / USB / storage fabric** = the long-lived memory substrate (storage-as-RAM).

## The memory factory
`transaction seen → learned immediately → saved as memory → cataloged → gulped → cubed → inherited`

The system does not keep raw experience forever. It turns experience into **reusable products**: notes · cubes · glyphs · catalog-reference-codes · internal tokens · supervisor promotions · PID lineage · recall entries · 3-D / 43-level spatial projections. **Memory stops being passive storage and becomes productive infrastructure.**

## The frozen-LLM shadow — behavioral distillation
An LLM can be treated like a **frozen spatial object**. Agents study its response-space **shadow** geospatially, learn what it tends to say, turn that into a **cube**, and descendants reuse the cube instead of re-querying the frozen model every time:

`frozen model → observed response-space shadow → agent study → cube → inherited behavior`

The agent disappears, but the cube remains. When needed, a new agent reappears **with the inherited cube, already upgraded.** The breakthrough: **agents do not need immortality — they need heredity.**
