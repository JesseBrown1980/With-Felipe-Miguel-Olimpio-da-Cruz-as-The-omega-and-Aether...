# asolaria-l1-prototype

Integer-only Rust port of the trained Asolaria L1 PrototypeGNN (`prototype_gnn.py`) with the weights of its run-1
checkpoint `prototype_model.pt` (sha256 `b4df9901...`), which `manifests/gnn_train_run1_results.json` names as the L1
checkpoint. Crate `asolaria-l1-prototype`, library `l1_prototype`, no dependencies, `#![forbid(unsafe_code)]`,
Rust 1.81, no `f32`/`f64`.

**Lane.** `src/` is hot lane: per request, in process, Q24 integers, no Python, torch, Node, JSON or HTTP.
`tools/` and `vendor/` are cold lane: they verify the port in CI. Provenance, the forward choice, the measured
agreement and what is not on disk are in [`PROVENANCE.md`](PROVENANCE.md).

**Integers.** The three tools use integer arithmetic only: `tools/quantize.py` reads each float32 weight of the
checkpoint by its bit pattern, and `tools/int_referee.py` decides the sigmoid from integer lower and upper bounds.
Float runs in one place, inside torch, when `tools/model_parity.py` runs the vendored `prototype_gnn.py` with the
trained float32 checkpoint (the owner's float32 lane, run unchanged); the tool builds its input tensors from float32
bit patterns and reads every output by its bit pattern. Before torch loads it pins the CPU kernels
(`ATEN_CPU_CAPABILITY=default`, `MKL_CBWR=COMPATIBLE`, one thread), as `model/l0-edge` does; on the x86-64 host that
wrote the fixture, `--check` passes with and without `MKL_ENABLE_INSTRUCTIONS=AVX2` and `ATEN_CPU_CAPABILITY=default`
set by the caller (the environments run are listed in [`PROVENANCE.md`](PROVENANCE.md#measured-agreement)).

## Modules

| Module | Port of | Public API |
|---|---|---|
| `weights` | `vendor/fnns/models/prototype_model.pt` as Q24 integers (generated by `tools/quantize.py`) | `PROTOTYPES`, `CONV1_W` ... `PROJ2_B` |
| `model` | `PrototypeGNN` (prototype_gnn.py:27-132) in eval mode with the checkpoint's layer layout: `conv1` and `conv2` are the file's fallback `GCNConv`, `self.lin(x)` (lines 17-24) | `encode_nodes`, `edge_outputs`, `forward`, `pair_output` (a helper added for this stack), `EdgeOutput`, `ModelError` |

Inputs are six Q24 values per node (`node_input_dim=6`) and edges `(source, target)` as node indices.
`edge_outputs` returns one `EdgeOutput` per edge with the three values the class computes for it: the edge
embedding (`get_edge_embeddings`, Q24), the two prototype logits (`compute_prototype_distances`, exact Q48) and the
`forward` value `softmax(logits)[1]` (Q24, round half up for every logit; near a half the side is decided exactly,
see [`PROVENANCE.md`](PROVENANCE.md)). `forward` returns that last value per edge. `pair_output(s, t)` has no
upstream method: it is `edge_outputs` of the two-node graph `[s, t]` with the edge `(0, 1)`. Upstream gives this
model no composite weight; none is set here.
