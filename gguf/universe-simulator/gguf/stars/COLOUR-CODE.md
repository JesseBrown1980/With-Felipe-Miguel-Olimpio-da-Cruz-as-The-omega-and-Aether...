# COLOUR CODE — every body measured under the pre-registered rule

Rule fixed in `receipts/FABLE5-PREREGISTER-COLOUR.hbp` on 2026-07-27, **before any
incoming body existed**. Each byte triple belongs to whichever channel dominates it;
ties are excluded (the free zero register). Nobody picks the colour — the bytes do.

| verdict | condition |
|---|---|
| RED / GREEN / BLUE | that channel leads by > 5% |
| ORANGE | R > G > B, R leads > 5%, **and** G − B > 5% |
| YELLOW | \|R − G\| ≤ 3%, **and** both exceed B by > 5% |
| NEUTRAL / GREY | all three within 3% |
